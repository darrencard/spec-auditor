# Automatic reminders

Illustrative sample brief for Acme, an invented company.

## Landing brief

- **Problem:** Invoices go unpaid because reminders depend on someone remembering to send them.
- **Metric:** Reminders sent per week
- **Bar:** 20,000
- **Better:** higher
- **By:** 2026-11-30
- **Non-goals:** No change to invoice terms.
- **Tokens per task:** 1,500
- **Price per token:** $0.000003
- **The line:** model call. The model writes the reminder wording; the schedule is fixed code.
- **Decides the next step:** Head of Product, Payments squad
